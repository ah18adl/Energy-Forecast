
# Appliance Energy Forecasting

Forecasting hourly appliance energy use in a low-energy house 24 hours ahead,
comparing benchmark models, SARIMAX, XGBoost and the Chronos foundation model.

Data: [UCI Appliances Energy Prediction](https://archive.ics.uci.edu/ml/machine-learning-databases/00374/energydata_complete.csv)
(Candanedo et al. 2017), 10-minute readings from January to May 2016, binned to
hourly means.

# Results

14-day test period, 24-hour horizon, re-forecast every 24 hours. MASE is scaled by
the in-sample daily seasonal naive error, so values below 1 beat that benchmark.

| model | MAE | RMSE | MAPE % | MASE |
| Chronos Bolt Small, zero shot | 34.7 | 69.0 | 25.4 | 0.649 |
| SARIMAX (5,0,6)(1,0,1,24) | 38.3 | 64.3 | 36.3 | 0.717 |
| XGBoost, conditional covariates | 41.4 | 65.0 | 42.1 | 0.774 |
| seasonal naive, weekly | 43.5 | 81.4 | 37.4 | 0.813 |
| XGBoost, strict covariates | 44.3 | 66.8 | 45.2 | 0.829 |
| seasonal naive, daily | 48.3 | 85.6 | 43.3 | 0.904 |
| mean | 50.3 | 74.9 | 53.7 | 0.941 |
| naive | 85.6 | 110.4 | 112.9 | 1.601 |
| drift | 85.8 | 110.7 | 113.3 | 1.606 |

Chronos wins on MAE, MAPE and MASE but loses to SARIMAX on RMSE. It forecasts
the median, so it tracks ordinary hours very closely (MAE about 19 Wh) and
declines to chase the evening spikes (MAE about 175 Wh on top decile hours).
Which model is preferable depends on whether large misses are disproportionately
costly.

Regenerated by `run_pipeline.py`; the current table is always in
`outputs/metrics/model_comparison.csv`.

# Quick start

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

python src/foundation.py     # Chronos forecasts, downloads ~190 MB of weights
python run_pipeline.py       # everything else, ~12 min (AIC grid dominates)
python run_pipeline.py --fast   # reuse the cached grid and SARIMAX parameters
```

Outputs land in `outputs/`: forecasts as CSV, the metrics table, and all figures.

# Layout

```
run_pipeline.py           end-to-end pipeline for Parts 1 to 8
notebooks/analysis.ipynb  step-by-step walkthrough of the same analysis
src/data_prep.py          load, check missing values, resample to hourly
src/eda.py                plots, decomposition, ADF and KPSS tests
src/benchmarks.py         mean, naive, seasonal naive, drift
src/sarima.py             AIC grid search, SARIMAX fit, diagnostics, intervals
src/features.py           sensor, weather, time, lag and rolling features
src/ml_model.py           XGBoost with recursive 24-hour forecasting
src/foundation.py         Chronos zero-shot forecasts
src/evaluate.py           metrics, forecast plots, error diagnostics
src/stages.py             run one modelling stage at a time
tests/test_pipeline.py    sanity checks, including feature leakage guards
outputs/                  forecasts, metrics and figures
```

Run the tests with `python -m pytest tests -q`. They check the hourly index is
complete, that lag and rolling features contain no information from the hour
being predicted, that the strict feature table has no contemporaneous
covariates, and that the benchmark and metric functions behave as defined.

# Method notes

* Every model is re-forecast from a rolling 24-hour origin, so no model sees test
  data before its own forecast origin.
* Lag and rolling features are shifted, and inside each 24-hour window the ML model
  feeds on its own predictions rather than test actuals.
* Two XGBoost variants are produced. The conditional one uses contemporaneous
  sensor and weather values, which would not be known in advance; the strict one
  lags those covariates by 24 hours so every input is available at the forecast
  origin. The gap between them is the value of perfect covariate knowledge.
* The AIC grid covers all 147 combinations of p = 0..6, d = 0..2, q = 0..6.
  Non-converged fits can return an absurdly low AIC, so they are flagged in
  `outputs/metrics/sarima_grid_aic.csv` and excluded from selection.
* ADF and KPSS both indicate the hourly series is stationary, so no differencing is
  applied; the daily cycle is handled by seasonal AR and MA terms at lag 24.
